# 📖 Minha Biblioteca Digital

Uma aplicação web de biblioteca pessoal feita com JavaScript, que permite adicionar, editar, listar e excluir livros — com suporte a **modo claro/escuro**, avaliação com estrelas, comentários, citações favoritas e **armazenamento local** via `localStorage`.

⚠️ **Aviso:** A persistência dos dados via localStorage está funcionando, mas apresenta um bug: para os livros reaparecerem após recarregar a página, é necessário alternar entre os modos claro e escuro.

## ✨ Funcionalidades

Adicionar novos livros com:
  - Título, autor, resumo
  - Imagem de capa personalizada (ou placeholder automático)
  - Avaliação com estrelas (de 0 a 5)
  - Comentário pessoal
  - Citação favorita

Além disso:
- Editar ou excluir livros já cadastrados
- Alternar entre tema **claro** e **escuro**
- Dados persistem usando `localStorage`
- Interface responsiva e interativa


## 📦 Organização

A aplicação é dividida em duas abas principais:

**📋 Meus Livros**: lista de livros cadastrados, ordenados alfabeticamente

**➕ Adicionar Livros**: para adicionar ou editar livros
